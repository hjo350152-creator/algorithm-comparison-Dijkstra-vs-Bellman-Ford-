Dijkstra vs Bellman-Ford — 최단 경로 알고리즘 동작 시각화

같은 그래프에서 두 알고리즘을 한 단계씩 동시에 실행합니다. 단계마다 “무엇을 했고 왜 그렇게 했는지”가 표시됩니다.

간선:현재 최단 경로 트리(prev) 지금 완화하여 갱신 지금 검사했지만 변화 없음 무시됨 / 음수 사이클  |  정점: 진한 파랑=지금 처리 중, 연한 파랑=확정, 연한 주황=거리를 아는 후보, 흰색=미도달  |  노란 상자=현재 dist, 표의 주황 칸=방금 바뀐 값  |  키보드: ← → 이동, Space 재생

Dijkstra

탐욕: dist가 가장 작은 정점을 꺼내 확정 → 그 정점의 간선만 완화 (우선순위 큐)

Bellman-Ford

동적 계획법: 모든 간선을 정해진 순서로 완화하는 라운드를 최대 V−1번 반복
간선 가중치 바꿔 보기 (직접 실험)

가중치를 바꾸고 “적용”을 누르면 두 알고리즘을 처음부터 다시 실행합니다. 간선 순서(번호)는 Bellman-Ford가 매 라운드 간선을 처리하는 순서입니다. 음수를 넣으면 Dijkstra가 틀리는 경우를 직접 만들어 볼 수 있습니다.

복잡도 요약
Dijkstra (이진 힙)Bellman-Ford
시간O((V+E) log V)O(V·E)
공간O(V+E)O(V+E)
음수 간선불가가능
음수 사이클 탐지불가가능

Dijkstra는 각 정점을 한 번만 꺼내 확정하므로 각 간선을 한 번씩만 본다. Bellman-Ford는 어떤 값이 최종값인지 알 수 없어 라운드마다 모든 간선을 다시 본다. 위 화면의 “완화 시도” 횟수 차이가 바로 이 차이다.
